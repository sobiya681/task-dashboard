# Notebook: Task Dashboard

## What it does

You add a task. You give it a priority. You move it along as you get it done — Pending, In Progress, Completed. And you can filter, sort, and search through it all when the list gets long.

That's it. No clutter, no 40 features you'll never use.

The things I actually use every day:
- Add a task with a title and optional description
- Set how important it is — Low, Medium, or High
- Move tasks through their stages as you work
- Search when you can't find something
- Filter by status or priority
- Sort by newest or oldest
- Flip on dark mode at night
- See your totals at a glance — how many are done, pending, or in progress

## How it's built

- Frontend: React + Vite (fast, simple, does the job)
- Backend: Node.js + Express
- Database: MongoDB Atlas with Mongoose
- Hosting: Vercel — frontend and backend both live there
